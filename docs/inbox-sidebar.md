# DSH 会话收件箱

在 DSH 侧边栏中浏览跨项目会话。每条会话显示项目图标、项目名称、活动时间与会话标题，保留置顶、稍后提醒、已收起和当前未发送的草稿。

`0.3.0` 保留收件箱组织方式，按 DSH 自身规范重写显示层。菜单、详情浮窗、状态点、对话框、输入控件、列表动画和拖拽预览直接使用宿主组件；不再打包 T3 组件、主题或拖拽引擎。适配本机 DSH Desktop `0.2.2-rc.1`。

`0.3.1` 将左下角账号入口改为 DSH 原生头像按钮，隐藏账号名称；点击仍打开包含设置、意见反馈及退出登录的原生菜单。

`0.3.2` 按最新要求改为点击头像直接打开设置，取消中间账号菜单。

`0.3.3` 将插件、自动化任务和更多移到底部，与头像设置共用一排图标。原有按钮、选中状态、导航与更多菜单继续由 DSH 维护。

`0.3.4` 去掉「更多」按钮和对应菜单入口，展开及收起侧栏都只保留头像设置、插件和自动化任务。

`0.3.5` 将新会话收进品牌右侧的小图标，取消独立按钮行，并压缩顶部品牌区与留白。

`0.3.6` 按已确认的两行方案隐藏独立品牌行；窗口控制在第一行，搜索、项目、新会话集中在第二行，添加项目收进项目菜单。

`0.3.7` 将展开时的侧栏开关对齐到 macOS 窗口按钮右侧，与关闭时的位置一致；关闭侧栏后隐藏新会话图标，收起过渡期间也不显示。全屏时两种状态共同使用宿主的左侧位置。

`0.3.8` 在 macOS 顶栏开关右侧显示 DSH 原生 DeepSeek 标志，复用鲸鱼图形与字标，融入已有第一行，不增加顶栏高度。

`0.3.9` 修复 logo 所在行的窗口拖动区域覆盖侧栏开关的问题，保留 logo 与开关的显示位置。

`0.3.10` 修复会话详情浮窗的黑底黑字，标题及正文显式沿用 DSH 原生详情浮窗的白色与浅灰色，深浅色均可读。

`0.3.11` 按确认的紧凑卡片方向重做会话详情：使用 DSH 菜单主题、圆角和阴影，默认只显示标题、项目、状态／相对时间。完整路径和精确时间放进对应行的次要悬停提示；窄窗口使用宿主的 inline 定位自动避让。

`0.3.12` 移除「待处理」标题和数量，普通会话列表直接接在搜索栏下；置顶、提醒和收起行为保留。

`0.4.0` 将「已收起」改为固定底部入口和侧栏内独立列表，主列表不再被展开内容挤占。两份列表分别保留搜索、项目筛选与阅读位置；已收起条目显示项目和时间，恢复、撤销和拖拽继续使用原数据模型。

`0.5.0` 按项目分组主列表，项目名称和图标作为组头，会话、草稿与提醒放在项目下面。直接订阅项目管理设置页的同一个控制器，名称、图标、置顶、归档及本机多目录分组同步生效；项目可折叠并提供新会话入口。底部「已收起」继续使用独立列表。没有项目管理插件时仍按 DSH 原生工作区分组，移除登记后仍保留可访问的会话。

`0.6.0` 按 T3 Code 的会话列表结构改为跨项目平铺：每条会话上方显示项目图标、项目名称与时间，下方显示标题和实际状态。同一项目可连续出现在不同条目中，不再显示项目组头、缩进或折叠。项目名称与图标继续实时联动设置；底部「已收起」保留独立列表和返回阅读位置。

## 安装

```sh
dsh plugin --profile desktop add "$PWD/releases/dsh-inbox-sidebar-0.6.0.tgz"
```

安装后完全退出 DSH，再重新打开，以重新加载插件。停用插件可恢复官方会话浏览区。旧版 `0.2.4` 安装包保留在 `releases/`，可重新安装回退。

## 界面与操作

- 窗口控制、新会话和全局面板继续使用官方组件。左下角复用原生 36px 头像，点击直接打开设置。
- 顶部使用两行：40px 窗口控制区，下面是 36px 的搜索、项目、新会话操作行。macOS 展开时在开关右侧显示紧凑 DeepSeek 标志；项目和新会话使用 28px 按钮及 16px 图标。侧栏开关在展开与关闭时保持同一位置；关闭时不显示新会话图标。新建动作及快捷键定义沿用宿主。
- 项目菜单包含项目筛选与添加项目，按实际权限和进行中的操作启用；收起侧栏的项目图标可展开同一个菜单。
- 插件、自动化任务位于侧栏底部，与头像共用一排 36px 图标按钮；名称在悬停时显示。侧栏收起时沿用原生竖排，不显示更多按钮。
- 会话采用双行，普通模式 64px、紧凑模式 52px。首行显示项目图标、会话置顶、项目名称和活动时间；第二行显示标题和实际状态。选中行使用 DSH 原生主题底色和边框，标题加粗。详情卡片使用 DSH 菜单主题，标题突出，项目与状态／相对时间各占一行。悬停项目行可查看完整路径，普通活动时间行的次要提示显示精确时间；运行、待回复和未读结果优先显示对应状态。
- 主列表跨项目平铺，保留会话置顶、活动顺序及手动排序；项目置顶只影响项目选择菜单。工作中会话持续可见，提醒显示真实到期时间。「已收起」固定在底部，点击切换独立列表，返回恢复原会话列表位置。
- 当前未发送的草稿单独位于顶部。新建会话使用官方入口；筛选项目后可在筛选行中为该项目新建会话。
- 搜索支持会话标题、项目、路径及宿主内容搜索；项目筛选使用 DSH Menu。搜索输入支持上下键与 Enter 打开结果，Esc 清除。
- 单击查看，双击标题或 F2 行内重命名。Enter 保存、Esc 取消、失焦保存；输入法组合态不触发保存，失败保留输入。
- 行尾与右键菜单使用宿主 Menu，提供打开、重命名、置顶、提醒、收起及恢复。提醒支持 1 小时后、明天 9 点、下周一 9 点和自定时间；自定时间使用宿主 Modal 与 Input。
- 拖拽使用 DSH 的 HTML Drag and Drop 方式和宿主拖拽预览，支持收起、恢复及跨项目的视觉排序，不改变会话所属目录。Esc、失焦或侧栏外释放取消。Option/Alt+↑↓ 可调整同类会话的显示顺序。
- 工作中、待回复、草稿及权限不足的操作按实际状态禁用。操作失败显示错误；整理会话后提供 5 秒撤销，⌘Z / Ctrl+Z 在文字编辑之外可用。
- 查看已收起会话不会自动恢复；明确恢复或出现新活动才回到待处理。输入框上方的收起状态提示继续保留。

## 偏好与数据

DSH「设置 → 会话侧边栏」继续提供显示密度、会话详情提示、收起状态提示、列表过渡动效及重置入口。列表动效调用宿主 AnimatedRows，并遵循减少动态效果设置。

偏好沿用 `dsh.inbox-sidebar.v1.preferences`。会话内容及置顶由 DSH 保存；本地收起、提醒和已读记录沿用 `dsh.inbox-sidebar.v1.session.`，手动顺序沿用 `dsh.inbox-sidebar.v1.order`。本版不迁移或清空已有记录。多个设备分别维护本地元数据。

本地「已收起」不等于宿主归档。查看宿主归档时按现有控制器规则恢复访问能力并保持本地收起归属。提醒由客户端时钟处理，关闭期间到期的提醒在重新打开后处理。

## 来源与实现

当前显示层位于 `src/native/`，数据控制器、状态模型和设置存储继续沿用。React、UI primitives 和图标由 DSH 提供，不在安装包中复制宿主实现。

早期 T3 移植源码及其来源清单保留在 `src/t3/` 和 `src/vendor/`，供历史核对；当前构建断言它们不进入安装包。相关许可证继续保留于 `THIRD_PARTY_NOTICES.md`。`verify:t3-drag` 与 `t3:import` 仅用于旧版材料。

## 快速验证

```sh
npm run check
npm run preview:build
npm run verify:native
node scripts/inspect-host.mjs
```

`verify:browser`、`verify:interactions`、`verify:settings` 和 `verify:tooltips` 指向同一组当前原生控件检查，不需要重复运行。

`npm run verify:details` 专项检查实际 DSH HoverCard 的浮层文字、深浅色对比度、DSH Polish 样式、长内容换行及关闭偏好。

隔离预览使用已安装 DSH 的真实 AppFrame、HeaderLeadingControls、SidebarRoot、React、UI primitives、图标与主题，配以示例会话及账号入口；不启动或操作用户 DSH 窗口。预览入口为 `temp/design/inbox-sidebar/index.html`；`?frame` 显示完整布局以核对完全关闭侧栏的状态。`npm run verify:header` 核对开关位置与关闭时的新会话入口。

实现规范见 [DESIGN.md](../DESIGN.md)。本机验收材料保留在未纳入版本控制的 `outputs/`。原生窗口中的操作手感仍需用户完全退出并重新打开 DSH 后确认。

## 项目管理插件

独立插件 [dsh-project-manager](../plugins/dsh-project-manager/README.md) 提供 T3 Code 风格的项目设置、自定义操作和多环境检出分组。它通过 DSH 原生工作区服务管理目录，保留当前会话收件箱侧边栏。
