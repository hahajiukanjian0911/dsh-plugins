# 设计约定

模式为 Operate。以用户提供的 T3 Code Settings → Projects 截图为组织参考，视觉完全跟随已安装的 DSH 0.2.2-rc.1 原生设置。

- 位置：原生 SettingsPanel 中的「项目」「环境」；使用 settings.section 和同 ID 的 settings.section.icon。
- 层级：项目/环境筛选 → 列表 → 项目基本信息、检出目录、项目操作、最近运行、移除。
- 控件：原生 Button、Input、Menu、Modal 和图标；面板、字体、文本、边界、圆角与状态色使用 DSH 的 dsw tokens。图标颜色为用户可选值，保证同组图标形态一致。
- 行为：列表条目进入项目详情；目录和操作以原生菜单收纳。短表单保护输入焦点，移除登记有明确确认；文件和会话保留在确认文案中说明。
- 环境范围：名称与操作列表可选择环境，图标和整理属于项目分组；动作列表不同时提示选择环境；离线目标不能启动会话、命令或打开目录。
- 错误：表单错误留在表单内；后台刷新不覆盖用户的写入错误或正在编辑的草稿。
- 渲染核对：离线加载实际 DSH SettingsPanel、React、UI primitives、图标和主题，示例 RPC 与导航；桌面原生面板宽 800px，窄屏另按 DSH Web 布局核对。截图等待原生弹窗淡入完成，点击命中确认弹窗在设置面板之上。

本版没有新增动效。原生窗口不由 Agent 激活，最终由用户重启 DSH 后上手核对。

0.1.2 将图标显示抽为 `src/identity.jsx`，设置页与会话侧栏共用；侧栏通过项目设置插槽的公开注入订阅同一个控制器，不另存名称、图标或检出分组。本机与远程检出以环境 ID 区分，当前侧栏只显示本机的会话。
