# DSH 项目管理

为在 DSH 中切换本机与远程项目的个人开发者，提供 T3 Code 风格的项目登记、检出目录分组和自定义命令管理。用户在 2026-11-11 明确要求把自定义脚本和多环境检出分组一起纳入首版。

工作区与会话以 DSH 原生服务为唯一来源；插件拥有分组、图标、整理、动作覆盖和环境凭据引用。设置页供用户完成操作，不在界面上展示实现过程。新版会话侧栏订阅本插件的同一控制器，以项目名称与图标分组会话。

成功标准：现有工作区自动可见；可编辑名称和图标；跨环境目录可自动或手动分组；新会话走原生入口；脚本在所选目录显式运行并可停止；移除登记保留文件与会话；失败保留输入并说明原因；离线环境不伪装为在线。

平台：DSH web 客户端及 macOS 桌面；后端使用公开 workspaceRegistry、storageDomain、credentials、Typert Remote 服务。首版细节与已知边界以 README 和验证记录为准。
