# DSH Polish

打磨 DSH 的视觉与交互细节，当前版本为 `0.1.44`。本插件与会话收件箱、项目管理分别打包和启停。

## 当前功能

- 输入框、下拉菜单、提示、用量统计和成员面板使用统一磨砂材质，跟随深浅色主题；减少透明度、增强对比度及强制颜色模式保留对应回退。
- 首页保留鲸鱼原生悬停互动与「探索未至之境」；项目／分支选择位于同一行右侧，输入框跨满标题行宽度。
- 输入区权限、模式等控件采用紧凑图标；项目管理 `0.1.5` 可将项目、分支和工作树集中在一个原生菜单中。
- 命令和技能候选每行左侧为名称、右侧为说明；长说明省略，悬停可读完整内容。
- 应用内滚动区域恢复浏览器原生滚动条，显示方式遵循运行环境。
- 隐藏对话正文两侧宽度拖动把手，在「设置 → 通用设置」提供「页面宽度」，沿用宿主已有偏好。
- macOS 使用与侧栏同色的 `32px` 标题栏和整体细边框；品牌、左右按钮对齐。原生红黄绿按钮位置由宿主决定，本插件安装不会修改宿主安装包。
- 统一图标、字体层级、设置页间距与圆角；新版下载入口保留蓝色并缩为图标。

`0.1.44` 将输入框占位提示恢复为宿主原生淡灰色：浅色 `#adb2b8`，深色 `#81858c`。增强对比度模式使用更清楚的提示色。

## 安装

在仓库根目录按[安装说明](../../README.md#从源码安装)安装开发依赖后执行：

```sh
npm run check --prefix plugins/dsh-polish
mkdir -p releases
npm pack ./plugins/dsh-polish --pack-destination ./releases
dsh plugin --profile desktop add "$PWD/releases/dsh-polish-0.1.44.tgz"
```

安装后正常退出并重新打开 DSH。插件行 ID 为 `polish`，显示名为「DSH Polish」。停用后撤销本插件注入的样式、监听和插槽扩展。

## 实现与验证

源文件位于 `src/`，通过 `scripts/build.mjs` 生成 `client.js`。修改时编辑源文件，再运行 `check`；不要直接编辑生成文件。React、原生编辑器、菜单和业务操作继续由宿主提供。

当前适配 macOS 上的 DSH Desktop `0.2.2-rc.1`。样式和部分控件适配依赖宿主组件结构，升级 DSH 后需要核对。插件不会在加载时改写模型、权限、字体偏好或 Git 配置。

后台预览和专项脚本位于 `scripts/`。预览提取本机已安装 DSH 的真实组件，配以隔离数据；部分历史对照脚本另需本机旧安装包及 `outputs/` 中的历史材料。这些本机记录不随 Git 仓库发布。
